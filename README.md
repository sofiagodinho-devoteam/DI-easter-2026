# Digital Maturity Assessment

**Devoteam Digital Impulse** — Internal assessment tool for evaluating digital maturity across People, Processes, Technology, and Data & AI dimensions.

## Access

This tool is restricted to Devoteam employees (`@devoteam.com` email required).

**Live URL:** `https://sofiagodinho-devoteam.github.io/DI-easter-2026/`

## Features

- **14-question assessment** across 4 dimensions with weighted sub-dimension scoring
- **AS-IS / TO-BE comparison** — save an AS-IS baseline, then assess TO-BE to see delta overlays on all charts
- **Interactive dashboard** with Dot Plot, Radar Chart, and Gap Analysis visualizations
- **PDF export** with full report including comparison data
- **Persistent storage** — assessments saved in browser localStorage
- **Consultant tracking** — records assessor name, date, and assessment reality

## How to Use

1. Open the live URL and enter your `@devoteam.com` email
2. Fill in Enterprise, Project, Consultant, and select AS-IS or TO-BE
3. Answer all 14 questions across the 4 dimensions
4. View the Dashboard with interactive charts
5. Export PDF for client deliverables
6. Save assessments for future reference or TO-BE comparison

## Updating

To update the tool, edit `index.html` and push to the `main` branch. GitHub Pages will redeploy automatically within ~1 minute.

## Tech Stack

Single-file HTML application using React 18 + Babel standalone. No build step required. All data stored client-side in localStorage.
